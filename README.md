# Argus

Argus is an evidence-first autonomous QA agent for web applications. This repository contains the initial monorepo foundation from the implementation dossier. The Python package has a working deterministic browser runner and evidence/report pipeline; model-driven exploration, adversarial review, and vision backends remain explicit extension points.

## Quick start

```powershell
cd packages/agent
python -m venv .venv
.venv\Scripts\Activate.ps1
cd ..\..
pip install -e packages\shared
pip install -e "packages\agent[dev]"
playwright install chromium
argus --url http://localhost:3100 --spec "Users can sign in and create an article" --output artifacts
```

After editing a contract model, regenerate schemas and frontend types with `make schemas`. Verify committed outputs with `make check-schemas`.

Run all golden role fixtures offline with `argus --stubs`; details are in [packages/agent/README.md](packages/agent/README.md).

Run the F-07 walking-skeleton smoke command with `make skeleton`. To exercise selected role replacements while keeping the rest on fixtures, use `argus --stubs --real explorer,tester`.

See [docs/HOW_TO_RUN.md](docs/HOW_TO_RUN.md) for setup, CLI options, and run examples.

The CLI currently performs a browser inventory pass and saves a run summary, NDJSON events, and artifacts under `artifacts/runs/<run_id>/`. Add journey JSON with `--journeys path.json` to execute deterministic steps and capture evidence. The sample app in Docker Compose is reachable at `http://localhost:3100`.

## Repository map

- `packages/agent`: Python agent, schemas, browser instrumentation, CLI and API.
- `packages/ui`: React + TypeScript dashboard, built with Vite.
- `packages/shared/schemas`: language-neutral JSON schemas.
- `apps`: sample applications and temporal bug rig.
- `benchmarks`: benchmark manifest and scoring scripts.
- `docs`: architecture, benchmark guidance, and source dossier.

See [docs/architecture.md](docs/architecture.md) and [docs/benchmark.md](docs/benchmark.md). Features outside the Stage 2 slice are marked as roadmap or stubs in code.

## Run the UI

```sh
pnpm install
pnpm dev
```

The page is available at `http://localhost:5173`. Use `pnpm lint` and `pnpm build` to check the UI package.
